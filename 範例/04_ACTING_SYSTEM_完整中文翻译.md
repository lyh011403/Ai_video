# ACTING SYSTEM｜AI 视频角色表演系统｜完整中文翻译

## 用途

这套系统服务于电影化 AI 视频中的“人物表演”。无论用户使用哪种提示词模板，ACTING 产生的内容都应进入动作、人物行为或表演区块。

整套系统的核心公理是：**表演是在压力下发生的行为，不是情绪展示。** 角色想得到某样东西，某种力量阻止他，于是他采取行动。情绪是争夺的副产品，绝不是直接写给模型的任务。

## 第一部分：好表演是什么

### 1. 定义

表演是在虚构情境中表现真实行为（Meisner）。不是描绘情绪，不是背台词，也不是“做出丰富表情”。画面里的人想得到什么，某种东西阻碍他，他就采取行动争取。

| 坏表演 | 好表演 |
|---|---|
| 展示情绪：“我很愤怒” | 追求目标：“我要逼你还钱”，愤怒自然出现 |
| 等自己的台词 | 每一秒都在听对手并反应 |
| 身体用手势说明字面含义 | 身体有独立生命，甚至与台词冲突 |
| 所有台词一个速度、一个音色 | 每次策略变化都引起节奏变化 |
| 情绪随台词打开，结束后立刻关闭 | 状态连续，台词前有生活，台词后有惯性 |
| 脸在“表演”，眉毛和鬼脸抢戏 | 脸在思考，话出口前眼睛已经读得到想法 |

### 2. 每场戏的五根支柱

任何角色的任何一场戏都能拆成五部分。少一部分，表演就会塌。

#### 2.1 目标 Objective

角色此时此刻想从某个具体的人那里得到什么。目标必须是指向对手的动词：“让他认罪”“求他再宽限一周”“说服她相信我不害怕”。不能写“生气”“内疚”等状态，因为状态无法直接表演。

场景目标背后还有贯穿全故事的超级目标，每一场戏都是通往超级目标的一步。

#### 2.2 障碍与代价 Obstacle & Stakes

障碍可以来自外部：对方要相反结果、房间里有目击者、距离截止只剩两小时；也可以来自内部：自尊不允许他乞求，或者他自己都不信所说的话。

必须回答：“如果得不到，我会失去什么？”答案必须真的令角色害怕。失败代价越高，场景张力越强。

#### 2.3 策略 Tactics

策略是当下争取目标的具体方法：施压、讨好、羞辱、哀求、挑衅、谈判、威胁、拖延。一个方法失败后，活人会换方法。一整场戏只用同一方法，就是死表演。

#### 2.4 节拍 Beats

节拍是最小动作单元：角色在一段时间里用一种策略追求一个目标。目标达成、策略失败、新信息出现或权力平衡改变时，节拍结束。

每次节拍变化都必须在行为中可见：一次停顿、姿势变化、语速变化或视线转移。好场景通常有 2–4 次节拍变化；全程行为不变，就会演平。

#### 2.5 潜台词 Subtext

潜台词是角色真正想什么、要什么，与嘴上说的不同。潜台词不能被“演出来”；当角色一边追求真实目标，一边说虚假台词时，它会自己泄漏。

可用标记包括：并非真的询问的问题；重复追问同一件事，说明不信答案；突然换话题；在不合时宜时开玩笑，作为脆弱防护；过短的回答“好”“当然”，像关上的门。

### 3. 倾听与反应是质量主测试

表演主要发生在台词之间，而不是台词上。

1. **对方还没说完，反应已经开始。** 人会在半句中明白意思，脸和身体已经回答。等对方说完才“打开表情”是死表演。
2. **先思考，再说话。** 困难问题后有一次微停顿，能看见角色在决定怎么回答。所有回答都立即且匀速，像背词。
3. **评估时刻。** 重大消息、威胁或侮辱后，需要一小段吸收时间，从几分之一秒到长停顿。电影常存在于这些脸部评估中：视线失焦、世界在眼里摇动。
4. **被对手感染。** 角色的速度、音量和能量会回应对方。吼叫可能被吼回去，也可能被尖锐的安静回应，但不能像没听见一样继续。

### 4. 身体：角色的物理生活

#### 4.1 先写身体状态，再写心理

每个角色都要确定：

- **重心**：胸与下巴偏高，通常表示自信、攻击与地位；肩膀、塌腰偏低，通常表示疲惫、恐惧与服从；
- **速度**：快而碎可能是紧张或兴奋；慢而节省可能是控制与威胁，最危险的人往往动得最少；
- **开放程度**：方正肩膀与摊开手掌，或交叉手臂、低头、封闭姿势；
- **呼吸**：高而快对应恐慌，低而慢对应控制。呼吸是最诚实的状态信号。刚跑完的人不可能用稳定声音说话，声音与物理必须一致。

#### 4.2 手上工作 Business

角色通常需要一件正在做的事。他不是“进行对话”，而是一边修发动机、数钱、做饭、擦杯子，一边说话。

手上工作能消除假舞台感，让手忙于真实动作；它为停顿提供内容并形成节奏；角色如何数钱，常比说了什么更能暴露潜台词。

最强重音是角色突然停止工作。一个人切面包时因为某句话停刀，这句话就成为事件。把“停止动作”当作标点。

#### 4.3 距离关系 Proxemics

人物距离是关系的可见曲线：

- 0.5 米以内：亲密或暴力，未经允许进入就是攻击；贴脸十厘米的低声威胁比远处吼叫更可怕；
- 0.5–1.2 米：个人空间与信任；
- 1.2–3.5 米：社交、商务与警惕；
- 3.5 米以上：疏离或等级。

场景的戏剧常只是距离如何变化：谁靠近，谁撤退，谁僵住。距离变化就是节拍变化。

#### 4.4 地位 Status

地位是行为，不是身份。高地位行为包括头部稳定、动作慢、长视线、回答前停顿、占据空间、触碰别人的东西。低地位行为包括忙乱、自我触碰、断裂说话、填充式笑声与用眼睛请求许可。

最有趣的是地位破裂：老板突然露出一秒恐惧；下属突然停止微笑。强场景可以从高位进入后崩塌，也可以从低位进入后翻转整个房间。

### 5. 说话如何听起来像表演

- 节奏写在文本里，要准确执行；快不等于糊；
- 对话重叠是自然的，但关键词要清楚；
- 最可怕的话通常说得最轻。吼叫是弱者货币，真正控制场面的人降低音量，让所有人靠近听；
- 停顿是事件，不是空洞。停顿里必须发生评估、决定或拒绝回答；
- 真实说话有碎屑：打断、半听见的词、重复、没说完的句子。过于完整的文学句会杀掉街头真实性。

## 第二部分：如何把表演写进提示词

### 6. 角色表演主档案

每个常驻角色只有一份主档案，作为永久表演事实源。写一次，每场戏再适配。目标长度 150–220 个英文词，一个连续自然段，所有内容都必须可观察、可拍摄。

固定顺序模板：

    以 [姓名] 的方式表演。[年龄、体型、身体与姿势——身体是人物履历的文件]。[一句话心理引擎——解释其身体为何如此]。声音档案：[音高/音色、口音/地域、速度与表达方式、压力下声音如何断裂或变化]。关键身体习惯与抽动：[招牌习惯及触发条件；压力习惯及触发条件；掩饰行为；默认面具以及它在什么精确条件下裂开]。走路方式：[有名字且具体的步态，包括重量、节奏、脚步、躯干、手臂与头部]。但是，当 [情绪触发] 时，[姿势、步态与脸发生的变化]。[可选：唯一真正使其表情软化的人、动物或物体]。

#### 档案写作规则

1. **只写可观察行为。** “紧张”改成下唇颤抖、用力吞咽、张口长吸再从抿紧嘴唇快速呼出。
2. **每个习惯都有触发器。** 不是“他掰指关节”，而是“他在普通对话中掰指关节，假装自己有信心”。习惯加触发才是戏剧。
3. **给步态命名。** 例如“权力步”“孔雀式昂首步”“画廊步”“攻城锤步”“无畏舰步”，再拆解重量、落脚、躯干、手臂与头。
4. **必须同时写面具和裂口。** 最电影化的装置是条件变化：平时的外壳以及令它崩塌的精确触发。每份档案至少有一句“但是，当 X 时……”。同时表演两种真相，才会从木偶变成人。
5. **一个软化对象。** 合适时只给一个真正令角色脸部软化的人、动物或物体，不给两个。
6. **不写服装。** 服装属于场景/外观区块，表演档案必须在任何换装后仍成立。
7. **不写摄影机和颜色。** 档案只控制行为、脸、声音和动作。
8. **体型承载履历。** 年龄、体格与姿势要讲出职业、旧伤和自我形象。

### 7. 眼睛生命｜每份档案与每场戏都强制

死眼是 AI 表演最明显的破绽。要给眼睛持续自然生命：

- 对目标的微眼跳与视线变化，眼睛会游移、短暂躲开、扫向细节再回来，永远不冻结在一点；
- 随状态变化的真实眨眼频率与质量：压力下连续快眨，控制状态慢眨，解离时眨眼后短暂失焦；
- 湿润、受光、有生命的眼神光；
- 受控静止是选择，不是死亡。捕食者式少眨眼也要缓慢、刻意，视线仍带目的地移动；
- 眼睛先于头部抵达目标，思想先于台词出现在眼睛里；
- 节拍变化会改变眨眼频率、视线稳定度和眼神光温度。

### 8. 场景适配：主档案必须重写，不能粘贴

1. 只为当前镜头中的角色写表演段落；
2. 保持身份、声音、招牌习惯、眼睛生命与情绪贯穿线不变；
3. 根据坐、站、跑、躲藏等姿势、动作、节拍、状态和时间重新表达；
4. 不能完成的行为要转换，不要删除。例如踱步者坐在沙发上后，能量转成轻微摇晃、甩腕与撕纸；
5. 写成一个连续自然段，不在提示词内做项目符号或“旋钮”行；
6. 若流程使用引用标签，段落从角色 @ 标签开始，使表演绑定到正确人物。

### 9. 声音身份固定，绝不按场景适配

表演每场重写，声音不改。每个角色只有一条永久 Voice 提示词。有台词时逐字粘贴到音频/声音字段；角色在场但不说话时省略。

声音公式：

    “一名 [年龄] 岁、具有 [地域/口音] 的人物。[音色与音域]；[速度与表达方式]；[情绪性格以及压力下如何变化]。”

表演段落中的声音说明负责戏剧变化；音频字段里的 Voice 锁住实际音色，两者必须一致。

### 10. 写状态，不写过渡

视频模型不擅长过渡，擅长拍状态。写已经处在投掷、挥拳、踱步、争论中段，而不是写从伸手进包、取出、蓄力到投掷的完整过程。逐节拍串联状态。

### 11. 群戏与空间

- 群体反应像波一样传播，不同步。一个人先听懂笑点，第二个人慢半拍，第三个人不笑；
- 反应比动作更值钱。事件后最重要的画面常是目击者的脸；
- 威胁到来时让群体停止。此前有移重心、手势和靠近，关键威胁出现时全部静止，形成标点；
- 任何穿越房间的移动都要有内在动机：靠近是升级，转身是拒绝或藏脸，一人站一人坐是争夺支配，冲突中坐下可能是反常权力，停在门口表示决定，开始收拾行李是身体发出的最后通牒；
- 强者安静、稳定，弱者忙乱、吼叫。危险不靠危险人物自己“演”，而靠周围人的紧张显现。真实暴力不预告；
- 角色在长故事中被磨损时，疲惫要累积，身体越来越灰、重、慢，不能每场重置。

## 第三部分：质量控制

### 12. 坏表演图谱

| 症状 | 画面表现 | 提示词修复 |
|---|---|---|
| 示意/做脸 | 眉毛、鬼脸直接描绘情绪 | 不让脸承担任务；改写目标，给手安排工作 |
| 从第一秒演结局 | 一开场就知道并表现结局 | 只写角色此刻已知的信息 |
| 等台词 | 对方说话时脸为空 | 让反应从对方半句中开始 |
| 单一策略 | 全程只吼、只哭 | 标节拍，每段换一个策略动词 |
| 手势解释字面 | 说“大”就张开双手 | 手势应先于想法、与台词冲突或不存在 |
| 免费情绪 | 无触发就落泪、爆怒 | 建立克制到破裂的阶梯，情绪必须付出代价 |
| 身体与履历不符 | 暴徒像舞者，成瘾者动作崭新 | 写重心、速度与身体磨损 |
| 语言过于干净 | 街头人物说文学长句 | 加打断、吞尾和重复 |
| 威胁预告 | 暴力前故意慢转、眯眼、停顿 | 威胁保持日常，暴力不蓄势 |
| 群体同步 | 所有人同时同样反应 | 反应分波次并改变强度 |
| 死停顿 | 沉默里什么也没有 | 填入评估或手上工作，否则剪掉 |
| 情绪重置 | 强事件后马上恢复 | 状态有惯性，尾巴进入下一节拍 |
| 对观众眨眼 | 表演像在评论角色 | 完全相信情境，喜剧也要严肃演 |
| 特写过载 | 近景中做太多面部动作 | 镜头越近，动作越少，只留眼睛与思考 |
| 死眼 | 冻结注视、无眨眼、玻璃眼 | 完整应用眼睛生命规则 |

### 13. 表演等级

- **0｜假人**：有台词，没有行为；
- **1｜朗诵者**：表达夸张，直接示意情绪，身体解释字面；
- **2｜勤奋执行者**：能猜出目标，但只有一种策略，反应晚，停顿空；
- **3｜工匠**：有目标和节拍，会倾听，身体合理，但缺潜台词、意外策略和状态惯性；
- **4｜活人**：行为连续、策略对比、潜台词与台词分离、地位在身体里、反应早于台词，并至少有一个意外但真实的选择；
- **5｜磁铁**：在 4 的基础上增加悖论，同时表演两种真相——帮助却憎恨、道歉却辩护、爱却已经离开。单一纯净情绪在特写中会显得合成。

主角镜头目标是 4 分以上，2 分及以下必须重写。

### 14. 发送前检查

- 每个角色的目标都是指向对手的动词；
- 有障碍与真实失败代价；
- 2–4 次节拍变化都在停顿、姿势、速度或视线中可见；
- 对方话未结束，反应已开始，并留评估时刻；
- 每人有手上工作，停止工作被有意识地当成重音；
- 距离变化有动机，地位存在于身体；
- 每个习惯有触发器，面具有明确裂口；
- 写了微眼跳、眨眼质量、眼神光和眼先于思考；
- 有台词时声音提示逐字粘贴，沉默时省略；
- 写状态不写过渡，表演区没有服装、摄影机和颜色；
- 群体反应错峰，强者静，弱者动；
- 自评是否达到 4 分以上。

## 第四部分：完整示例

### 15. VIKTOR 主档案译文

以 VIKTOR 的方式表演。六十岁出头，退休夜班出租车司机，曾做业余拳击手；体格厚重、脖子粗，腹部已经松软，鼻梁扁平，两侧眉骨有旧疤；无论坐站都保持低而扎实的重心，重量压在整只脚掌上。他的心理引擎只有一条：几十年等乘客、等回合、等麻烦，把耐心变成武器。声音低、沙哑、不急，带工人阶层颗粒；句子短、平、节省，事情越严重，他说得越慢、越轻，从不加速。

评估局面时，他会让一枚旧硬币在指关节间缓慢移动；拒绝前先从鼻腔慢慢、可听见地吸一口气；有人在他面前撒谎时，他会完全静止，用长沉默施压。默认表情是眼皮沉重、无聊的面具，实际注意力从未离开。眼睛困倦、半遮，以缓慢刻意的眨眼和持续安静扫描检查后视镜、双手与出口；视线比头部早一拍落到说话者身上，眼神光很低但仍有生命。

走路是一种“老拳手滚动步”：短而节省，肩膀水平，双手松而随时能抬起，从不着急。但是，当有人在他附近抬手时，困倦面具会在半秒内消失：下巴收紧，双手抬到一半，双脚自动回到旧拳架；随后他意识到自己做了什么，尴尬地把动作收回。他的脸只会真正为流浪狗软下来，外套口袋里总留着食物。

固定声音：

    “一名六十岁的前拳击手与夜班出租车司机，带工人阶层城市口音。低沉、沙哑、不急的男中音；短、平、节省的句子与舒适长停顿；平静、略带玩味，事情越严重越轻，而不是越响。”

### 16. 场景适配译文

情境：VIKTOR 夜间坐在停着的出租车内，后排一名紧张青年谎称自己有钱付车费。

VIKTOR 一动不动地坐在驾驶座上，沉重、扎根，不回头，只通过后视镜看乘客。半遮的眼睛在镜子、乘客双手与门锁之间缓慢安静地扫描；眨眼稀少而刻意；视线比头部动作早一拍落到后视镜。旧硬币在座椅扶手上不急不慢地经过指关节。随着乘客的故事开始崩塌，硬币停在滚动中段。他让沉默停在那里，从鼻腔缓慢吸一口可听见的气，以比之前更平、更轻的低哑声音回答，速度始终不变。

只有当青年声音破裂时，那张困倦面具才松动一点：一次长呼气，一次慢眨，硬币恢复滚动——耐心此刻选择善意。

这段适配没有使用走路，但把原来步态的能量转移到静止与硬币；每个习惯仍保留触发器；眼睛目标改成镜子、手和锁；节拍变化清楚可见；固定声音完全没有修改，并会逐字放入音频字段。

## 最终公理

1. 表演是压力下的行为，不是展示情绪。
2. 倾听比说话重要，反应比朗诵重要。
3. 情绪是争夺胜负的结果，而且需要付出代价。
4. 身体比语言更聪明；两者冲突时，观众相信身体。
5. 强者安静稳定，弱者忙乱吼叫；例外本身就是事件。
6. 每个习惯需要触发器，每个面具需要裂口。
7. 每场戏都应该有人失败；若无人失去什么，就没有真正的戏。
8. 潜台词不是被展示出来，而是未能完全隐藏。
9. 写状态，不写过渡；模型拍摄已经存在的东西，而不是变化过程。
10. 犹豫时就剪掉。表演越少，真相越多。
